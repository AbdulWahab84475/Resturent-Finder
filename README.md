# 🍽️ Pakistan AI Restaurant Finder

An AI-powered restaurant discovery application focused on major cities in Pakistan.

## What the app does

The app:

1. Finds nearby restaurants using Google Places API.
2. Shows restaurant rating.
3. Shows customer review count.
4. Calculates distance.
5. Shows price level.
6. Shows restaurant address.
7. Provides a Google Maps link.
8. Retrieves available customer reviews.
9. Uses Groq to analyze customer feedback.
10. Identifies dishes mentioned by customers.
11. Identifies positive and negative feedback.
12. Researches mentioned dishes for general context.
13. Produces a Customer-Backed Verdict.

## Technology

- Python
- Google Places API
- Groq
- Streamlit
- GitHub
- Streamlit Community Cloud
